## Gocgun.* — .NET building blocks I build in the open

Small libraries and tools with one job each. The READMEs state their limits plainly. Beta, MIT licensed, NuGet publishing set up.

| Area | Repositories |
|---|---|
| Messaging | [Gocgun.Bus](https://github.com/farukgocgun/Gocgun.Bus): RabbitMQ and in-memory transports, named buses, dead-lettering, idempotency · [Bus.Outbox.InMemory](https://github.com/farukgocgun/Gocgun.Bus.Outbox.InMemory) |
| Caching | [Gocgun.Cache](https://github.com/farukgocgun/Gocgun.Cache): L1 memory + L2 Redis with pub/sub invalidation |
| Application core | [Gocgun.Mediator](https://github.com/farukgocgun/Gocgun.Mediator) · [Gocgun.Results](https://github.com/farukgocgun/Gocgun.Results) · [Results.Http](https://github.com/farukgocgun/Gocgun.Results.Http) (problem+json) |
| RPC | [Gocgun.Grpc](https://github.com/farukgocgun/Gocgun.Grpc): unary calls, mandatory deadlines, no payloads in logs |
| Diagnostics | [Bus.Ui](https://github.com/farukgocgun/Gocgun.Bus.Ui) · [Cache.Ui](https://github.com/farukgocgun/Gocgun.Cache.Ui): read-only, loopback-only RabbitMQ and Redis inspectors |
| Utilities | [Gocgun.Extensions](https://github.com/farukgocgun/Gocgun.Extensions) |

**Principles across them:** fail at startup, not in production · explicit contracts (protobuf-net, no code generation) · read-only tooling by default · document the limits honestly.
